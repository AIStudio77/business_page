# Design Guidelines for Tech Company Website

## Design Approach
**Reference-Based Approach**: Drawing inspiration from modern tech companies like Linear, Notion, and Apple's clean aesthetic, emphasizing bright, minimalist design with futuristic elements while maintaining professional credibility.

## Core Design Elements

### A. Color Palette
**Primary Colors:**
- Light Mode: 210 100% 95% (light blue-gray background), 220 91% 18% (deep navy text)
- Dark Mode: 220 91% 8% (dark navy background), 210 100% 95% (light text)

**Brand Colors:**
- Primary Tech Blue: 214 84% 56% (vibrant but professional)
- Accent Cyan: 185 84% 65% (for highlights and interactive elements)

**Background Treatments:**
- Subtle geometric patterns or grid overlays
- Light gradient overlays: 210 50% 98% to 220 30% 96%
- Bright, clean surfaces with minimal shadows

### B. Typography
**Font Families:**
- Primary: Inter (Google Fonts) - clean, modern, highly readable
- Headings: Space Grotesk (Google Fonts) - geometric, tech-forward feel

**Hierarchy:**
- Hero titles: 3xl-4xl, medium weight
- Section headers: xl-2xl, medium weight
- Body text: base-lg, regular weight
- Captions: sm, medium weight

### C. Layout System
**Spacing Units:** Tailwind units of 2, 4, 6, 8, 12, 16
- Micro spacing: p-2, m-2
- Component spacing: p-4, p-6, m-4, m-6
- Section spacing: p-8, p-12, m-8, m-12
- Large spacing: p-16, m-16

### D. Component Library

**Navigation:**
- Clean horizontal navigation with subtle hover states
- Floating theme toggle (top-right corner)
- Floating chat button (bottom-right, subtle shadow)

**Carousel System:**
- Large, prominent carousel showcasing tech services
- Smooth slide transitions with momentum scrolling
- Media containers supporting both images and videos
- Hover-triggered information panels that slide up smoothly

**Dynamic Menu:**
- Context-sensitive menu that morphs based on carousel selection
- Clean button styling with subtle borders
- Dropdown or slide-out panels for additional options

**Cards & Content:**
- Minimal card design with subtle borders
- Generous whitespace and padding
- Clean information hierarchy

**Interactive Elements:**
- Buttons with subtle shadows and clean corners
- Hover states with gentle color transitions
- Focus states for accessibility

### E. Animations
**Minimal, purposeful animations:**
- Carousel transitions: smooth slides with easing
- Hover reveals: gentle slide-up animations for information panels
- Menu morphing: smooth transitions between dynamic menu states
- Theme switching: fade transitions between light/dark modes

## Visual Treatment

### Futuristic but Grounded Elements
- Subtle geometric shapes and grid patterns
- Clean lines and minimal visual noise
- Technology-inspired iconography from Material Icons
- Bright, optimistic color usage avoiding heavy dark themes

### Content Presentation
- Hero carousel prominently featured above the fold
- Information panels that appear on hover without disrupting layout
- Clear visual hierarchy emphasizing the company's tech expertise
- Professional photography showcasing IoT devices, smart homes, and technology solutions

### Images
**Hero Carousel Images:**
- High-quality images of smart home setups, IoT devices, and domotic solutions
- Clean, bright photography with consistent lighting
- Images showing technology in real-world, approachable contexts
- Video capabilities for demonstrating chatbot interactions or smart home functionality

**Supporting Visuals:**
- Technology iconography throughout the interface
- Subtle pattern overlays for visual interest without distraction
- Clean product photography for the products section

### Responsive Considerations
- Mobile-first carousel with touch-friendly interactions
- Simplified navigation on smaller screens
- Maintained visual hierarchy across all device sizes
- Optimized media loading for performance

This design creates a bright, professional, and approachable tech company presence that emphasizes innovation while remaining grounded and trustworthy for potential clients seeking domotic and IoT solutions.
